# Моё учебное портфолио

Это сайт-портфолио с учебными материалами по информационным технологиям, JavaScript и проектами Figma Make.

## Как открыть сайт

1. Откройте `index.html` в браузере или опубликуйте папку проекта через GitHub Pages.
2. На главной странице выберите нужный раздел.
3. В разделе «Проекты Figma Make» находятся три ссылки: сайт кинотеатра, магазин одежды и учёт личных финансов.

## Что находится в папках

- `index.html` — главная страница портфолио.
- `5-6-7неделя/` — семь учебных проектов JavaScript. Внутри проектов находятся HTML-файлы, `script.js` и, где требуется, `style.css`.
- `bezopasnaya-rabota/` — отдельный мини-сайт о безопасной работе за компьютером.

## Для чего нужны файлы

- **HTML** — структура страницы: заголовки, текст, карточки, кнопки и ссылки.
- **CSS (`style.css`)** — внешний вид: цвета, фон, размеры, расположение элементов и адаптация под экран.
- **JavaScript (`script.js`)** — действия и интерактивность: обработка нажатий, вычисления, поиск и изменение данных.
- **README.md** — описание проекта и инструкция по запуску.

## Как посмотреть код Figma Make

1. Откройте одну из ссылок Figma Make в разделе «Проекты Figma Make».
2. Перейдите во вкладку **Files**.
3. Откройте нужный файл, чтобы посмотреть код.
4. Чтобы скачать исходники целиком, откройте **File actions → Download code**.

Примечание: ссылки Figma Make ведут на оригинальные проекты в Figma. Их исходный код не подменяется выдуманными файлами в этом GitHub-архиве.

## Публикация на GitHub Pages

Загрузите в корень репозитория `index.html`, `README.md` и обе папки целиком. В настройках репозитория откройте **Settings → Pages**, выберите публикацию из ветки `main` и папки `/(root)`.
