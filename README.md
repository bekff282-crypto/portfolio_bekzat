# Портфолио Бекзата Баймурзинова

Учебное портфолио веб-дизайнера, группа WD-2-135.

## Запуск
Открой `index.html` в браузере.

## Публикация на GitHub Pages
1. Создай репозиторий на GitHub.
2. Загрузи все файлы и папки проекта.
3. Открой Settings → Pages.
4. В разделе Build and deployment выбери Deploy from a branch.
5. Выбери ветку `main` и папку `/ (root)`, затем Save.

## Что нужно заменить/добавить перед сдачей
- Добавить собственные скриншоты учебных работ в `assets/screenshots/`.
- Добавить собственный рендер Blender в `assets/blender/` и вставить его в раздел Blender.
- Создать три собственных интерактивных прототипа Figma и вставить ссылки.
- Подключить настоящую базу данных и серверную обработку формы. Сейчас форма только проверяет поля в браузере и НЕ сохраняет их.
- Проверить все материалы и описания: оставлять только реально выполненные работы.

## Структура
- `index.html` — структура сайта.
- `style.css` — оформление.
- `script.js` — интерактивные функции.
- `assets/` — изображения и материалы.
